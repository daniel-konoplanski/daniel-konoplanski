## 📁 Projects

### [ramiel](https://github.com/daniel-konoplanski/ramiel)
Lightweight desktop hardware monitor for Linux — CPU, GPU, memory, storage, network, and display metrics without root access. Reads sensors directly from sysfs/hwmon, with live per-second charts on a customizable dashboard. Built with Tauri v2, Rust, and Svelte.

### [p2p_ft](https://github.com/daniel-konoplanski/p2p_file_transfer)
Minimal peer-to-peer file transfer tool for Linux. Direct encrypted transfers between two machines over TLS 1.2+ with auto-generated ECDSA certificates, chunked streaming, interactive approval prompts, and real-time progress tracking. Built in C++23 with Boost.Asio and Protocol Buffers.

### [bf2_memhack_v2](https://github.com/daniel-konoplanski/bf2_memhack_v2)
Internal cheat for Battlefield 2 and compatible mods (Forgotten Hope 2, Project Reality). Toggleable player nametags with distance, minimap maphack, and a simple in-game UI menu.

### [silverspark](https://github.com/daniel-konoplanski/silverspark)
AFK barding-salvage bot for Conqueror's Blade. Automates buying vendor items and salvaging them in bulk by driving the DirectX game client with deterministic move-settle-click input injection, toggled by a global F12 hotkey. Python with pydirectinput, managed with uv.

### [bitmap_manipulator](https://github.com/daniel-konoplanski/bitmap_manipulator)
Windows Forms desktop app demonstrating four classic image filters — grayscale, reflection, blur, and edge detection — with real-time preview. C# on .NET Framework.

### [cpp_project_template](https://github.com/daniel-konoplanski/cpp_project_template)
A straightforward C++ project template to get things rolling quickly:

- Clean folder layout: `src`, `include`, `tests`
- CMake build system with example toolchains for different platforms
- clang-format and clangd ready for consistent styling and editor support
- vcpkg integration for dependencies
- Basic `main.cpp` to kick off an app or library
